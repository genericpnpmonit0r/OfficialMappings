using various shitty tools to make a merged workspace (this is only general guidance, i wont go in to the specifics)

1.
open the client and server mappings in enigma with the corresponding jar
save as tiny v2

2.
open the mappings in a text editor and change the following fields at the top:
from: (it might vary but just replace the first line in the file)
tiny	2	0	obfuscated	deobfuscated
to
tiny	2	0	official	named
save them as you will need them in the next step

3. 
set up retromcp-java (only tested on v1.0-pre1, mapping formats might have changed after that), select b1.3_01 as the version, let it set it up
now, go in the conf directory, delete client.exc, server.exc and replace client.tiny and server.tiny with the mappings you saved from enigma and edited

3.1.
for pc gamer demo you will have to select b1.3-pcg in retromcp-java and use the pcgamer demo version of the mappings and repeat step 2 but with client.tiny only

4.
click decompile
you will have to fix the exception errors manually since i could not be arsed to make .exc files for these since its a bunch of painful manual labor so eh

5.
the rest is patch/winmerge/etc hell unless you figure out a clean way to automerge the missing parts of client adn server together
